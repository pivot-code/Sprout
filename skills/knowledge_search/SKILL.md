# 知识库检索

## 什么时候用

当用户提出以下类型的需求时使用：

- "我之前存过关于 XXX 的东西吗"
- "我之前读过关于 XXX 的论文吗"
- "找一下我关于 XXX 的笔记"
- "我的知识库里有关于 XXX 的内容吗"
- "我之前写过 XXX 的东西吗"

只要用户想**从自己的知识库里找东西**，就用这个 skill。

## 怎么用

调用 `search_knowledge` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `query` | 是 | 搜索关键词 |
| `scope` | 否 | 搜索范围，默认 `all` |
| `max_results` | 否 | 返回几个结果，默认 5 |

### 关于 scope

- 用户说"我之前读过关于 XXX 的论文吗" → `scope="papers"`
- 用户说"我的课程笔记里有没有 XXX" → `scope="courses"`
- 用户没说 → 默认 `all`

可选的 scope：`all` / `courses` / `papers` / `digests` / `cards` / `comparisons` / `maps` / `arxiv_papers` / `reports`

## 输出

工具返回 top N 相关文件，每个包含：

- 文件名
- 路径
- 相关度（高 / 中 / 低）
- 为什么相关
- 内容预览（前 300 字）

**你应该：**

- 把结果展示给用户
- 如果用户说"我要看第一个"或"给我看看那个"，用 `read_file` 读取对应路径的完整内容
- 如果没找到相关文件，如实告诉用户"没找到相关笔记"

## 示例

**例 1：搜全部**

用户："我之前存过关于 RLVR 的东西吗"

做法：调用 `search_knowledge(query="RLVR")`。

**例 2：只搜论文**

用户："我读过关于语言漂移的论文吗"

做法：调用 `search_knowledge(query="语言漂移", scope="papers")`。

**例 3：搜到后看全文**

用户：（看到结果后）"看看第二个文件"

做法：根据工具返回的路径，用 `read_file` 读取那个文件，展示给用户。

## 注意

- 搜索是**基于关键词 + LLM 相关度判断**的，不是全文检索
- 如果结果里没有用户想要的，可能需要换关键词再搜一次
- 工具**只返回文件位置和预览**，不返回全文。要看全文，用 `read_file`
- 不要主动调用本工具。用户没要求找东西时，不要动
