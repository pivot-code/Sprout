# 论文对比

## 什么时候用

当用户提出以下类型的需求时使用：

- "对比这几篇论文"
- "它们有什么区别"
- "这几篇之间的关系是什么"
- "帮我比较 A 和 B（论文）"
- "这几篇论文有什么共同点和差异"

只要用户想**对比多篇论文**，就用这个 skill。

## 怎么用

调用 `compare_papers` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `paper_ids` | 是 | 逗号分隔的论文标识（papers/ 下解读文件名的前缀），如 `2610.02191,2610.01372`。支持 2-5 篇 |
| `focus` | 否 | 对比重点，如 `methods`、`experiments`。留空则全面对比 |
| `save` | 否 | 是否保存到 `papers/_对比/`，默认 true |

### 关于 paper_ids

**这是最关键的部分。** 用户可能这样说：

- "对比 2610.02191 和 2610.01372" → 直接用这两个 ID
- "对比这篇和那篇"（上下文里有） → 需要你从上下文里找出对应的 ID
- "对比我刚解读的那几篇" → 需要你查看 `papers/` 下最近的解读文件，找出 ID

**如果用户没给明确的 ID**，先用 `terminal` 列出 `papers/` 下有哪些解读文件：

```
dir papers\*_解读.md
```

然后根据文件名（去掉 `_解读.md` 后缀）提取 ID。或者向用户确认要对比哪几篇。

### 关于 focus

- 用户说"重点对比它们的方法" → `focus="methods"`
- 用户说"看看实验上的区别" → `focus="experiments"`
- 用户没说 → 留空，全面对比

## 输出

工具会把对比文档保存到：

- `papers/_对比/{时间戳}_{IDs}.md`

并在对话里返回全文。

**你应该：**

- 把对比全文展示给用户（它是核心产出）
- 告诉用户保存在哪

## 示例

**例 1：明确 ID**

用户："对比 2610.02191 和 2610.01372"

做法：调用 `compare_papers`，`paper_ids="2610.02191,2610.01372"`。

**例 2：上下文里提到的**

用户："把我刚才解读的那几篇对比一下"

做法：先用 `terminal` 查 `papers/` 下最近的解读文件，提取 ID，
再调用 `compare_papers`。

**例 3：指定重点**

用户："对比这几篇的方法：2610.02191,2610.01372"

做法：调用 `compare_papers`，`focus="methods"`。

## 注意

- **必须先对每篇论文跑过 `analyze_paper`**。如果某篇没找到解读文件，
  工具会提示用户先解读
- 一次最多 5 篇，超过会报错
- 对比文档是给用户看的，**全文展示**
- 不要主动调用本工具。用户没要求对比时，不要动
