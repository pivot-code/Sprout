# 自测题生成

## 什么时候用

当用户提出以下类型的需求时使用：

- "从智能感知技术出一套题"
- "给我出几道题自测一下"
- "帮我做个小测"
- "出 5 道关于这门课的题"
- "我想检验一下学得怎么样"

只要用户想**检验自己对某门课/某份资料的掌握程度**，就用这个 skill。

## 怎么用

调用 `generate_quiz` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `course_name` | 否 | 从哪门课出题，如 `智能感知技术`。留空表示从所有课程出题 |
| `num_questions` | 否 | 出几道题，默认 5 |
| `question_types` | 否 | 题型，逗号分隔：`choice` / `fill` / `short`，默认全出 |
| `save` | 否 | 是否保存到 `quizzes/`，默认 true |

### 关于 course_name

- 用户明确说了课程名（"从计算机网络出题"）→ 填进去
- 用户说"从我的笔记里出题" → 留空，从所有课程出
- 用户没提课程 → 如果对话上下文里有明确的课程，用它；否则留空

### 关于 question_types

- 用户说"只出选择题" → `choice`
- 用户说"来几道填空题和简答题" → `fill,short`
- 用户没说 → 默认 `choice,fill,short`

## 输出

工具会把题目和答案**分开保存**：

- `quizzes/{课程名}/{时间戳}_quiz.md` —— 只有题目
- `quizzes/{课程名}/{时间戳}_answers.md` —— 只有答案

**关键规则：**

- 对话里**只展示题目**，不要主动展示答案
- 展示完后，告诉用户"做完可以跟我说'看答案'"
- 用户说"看答案""对答案"时，用 `read_file` 读取对应的 `_answers.md`，展示给用户
- 如果用户想重新做一遍，可以重新出题（新时间戳）

## 示例

**例 1：从某门课出题**

用户："从智能感知技术出 5 道题"

做法：调用 `generate_quiz`，`course_name="智能感知技术"`，`num_questions=5`。

**例 2：只出选择题**

用户："给我出 3 道单选题，从计算机网络的笔记里"

做法：调用 `generate_quiz`，`course_name="计算机网络"`，`num_questions=3`，`question_types="choice"`。

**例 3：看答案**

用户（在做完题后）："看答案"

做法：用 `read_file` 读取最近的 `quizzes/{课程名}/{时间戳}_answers.md`，展示给用户。

**例 4：还没有笔记**

用户："从量子力学出题"

如果 `courses/量子力学/` 不存在，工具会返回提示。把提示转述给用户，建议他先用 `digest_course_material` 消化一些资料。

## 注意

- **不要主动展示答案**，除非用户明确要求
- 不要在对话里贴出整个答案文件（可能很长），只展示用户要的部分
- 如果用户做完题想让你批改，让他把答案发给你，你对照 `_answers.md` 逐题批改
- 一次出一套题，不要一次性生成多套
