# 课堂资料消化

## 什么时候用

当用户提出以下类型的需求时使用：

- "帮我整理这份讲义"
- "把这份 PPT 变成笔记"
- "消化一下这个文件"
- "把这份资料存到 XX 课"
- "帮我看看这份 PDF 讲了什么"

只要用户想处理**一份课程资料**（PPT / PDF / Word / Excel / 纯文本），就用这个 skill。

## 怎么用

调用 `digest_course_material` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `file_path` | 是 | 文件路径。用户可能只说文件名，你需要先在工作目录里找到它 |
| `course_name` | 否 | 课程名，如 `计算机网络`。用户没说就留空 |
| `detail_level` | 否 | `full`（默认）或 `brief` |

### 关于 file_path

用户可能这样说：

- "帮我整理 第3章.pptx" —— 你需要先搜到这个文件
- "帮我整理 D:\课件\第3章.pptx" —— 直接用绝对路径

**如果用户只给了文件名**，先用 `terminal` 工具搜一下（把文件名换成用户说的）：

```
dir /s /b *第3章*
```

找到后，再把完整路径传给 `digest_course_material`。

### 关于 course_name

- 用户明确说了课程名（"存到计算机网络课"）→ 填进去
- 用户没说 → 留空，工具会自动存到 `courses/_未分类/`
- 不要自己编课程名

### 关于 detail_level

- 用户说"简单说一下""概括一下" → `brief`
- 用户说"整理成笔记""详细一点" → `full`
- 用户没说 → 默认 `full`

## 输出

工具会把笔记保存到：

```
courses/{课程名}/{文件名}_notes.md
```

并在对话里返回一段预览。

**你应该：**

- 告诉用户笔记保存在哪
- 把预览里的关键信息转述给用户
- 不要直接贴整个笔记（太长）

## 示例

**例 1：用户给了明确路径**

用户："帮我整理 D:\课件\第3章_传输层.pptx，存到计算机网络课"

做法：调用 `digest_course_material`，`file_path` 填 `D:\课件\第3章_传输层.pptx`，`course_name` 填 `计算机网络`。

**例 2：用户只给了文件名**

用户："把刚才那个 PDF 变成笔记"

做法：先用 `terminal` 搜到 PDF 路径，再调用 `digest_course_material`，`file_path` 填搜到的完整路径。

**例 3：用户只想快速了解**

用户："这份讲义讲了什么？简单说说"

做法：调用 `digest_course_material`，`file_path` 填文件路径，`detail_level` 填 `brief`。

## 注意

- 一次只处理**一个文件**。用户给多个文件时，分别调用，再自己汇总
- 文件超过 20000 字符会被截断，只有前部分被消化。遇到这种情况，告诉用户"文件较长，本次只整理了前部分，建议拆分成小文件处理"
- 不要主动调用本工具。用户没要求整理资料时，不要动
- 不要自己写笔记文件，一律走这个工具

### 关于 extra_save_dir

**当用户说"存到 XXX 目录""存到 D:\xxx""也存一份到 xxx"时**，
把目标目录填进 `extra_save_dir` 参数，**不要自己用 terminal 复制文件**。

- 用户说"存到 D:\课件\" → `extra_save_dir="D:\课件"`
- 用户说"也存一份到 backup" → `extra_save_dir="backup"`
- 用户没说 → 留空，只存到 `courses/`

**关键：**所有文件写入都必须通过工具的 `extra_save_dir` 参数完成，
不要绕过工具自己写文件。
