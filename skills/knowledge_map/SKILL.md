# 知识地图生成

## 什么时候用

当用户提出以下类型的需求时使用：

- "帮我梳理一下知识"
- "生成知识地图"
- "我学的这些东西有什么关系"
- "画一张知识图"
- "把课程内容串起来"

只要用户想**看到知识之间的整体关系**，就用这个 skill。

## 怎么用

调用 `build_knowledge_map` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `course_name` | 否 | 只处理某门课。留空表示处理所有课程 |
| `save` | 否 | 是否保存到 `maps/`，默认 true |

### 关于 course_name

- 用户说"梳理一下智能感知技术" → 填课程名
- 用户说"梳理我的所有笔记" → 留空
- 用户没说 → 如果有明确的上下文课程，用它；否则留空

## 输出

工具会把知识地图保存到：

- `maps/知识地图_{日期}.md`

并在对话里返回预览。

**你应该：**

- 告诉用户保存位置
- 把预览展示给用户
- 如果用户想看完整版，用 `read_file` 读取文件

## 示例

**例 1：全部课程**

用户："帮我梳理一下我学的所有东西"

做法：调用 `build_knowledge_map`，`course_name` 留空。

**例 2：某门课**

用户："给我看一下智能感知技术的知识地图"

做法：调用 `build_knowledge_map`，`course_name="智能感知技术"`。

## 注意

- 本工具会**逐门课调 LLM 抽取概念**，如果课程多，会比较慢（每门课几秒到十几秒）
- 告诉用户"正在分析，请稍等"
- 知识地图是给用户看的，**展示预览 + 告诉他文件位置**
- 不要主动调用本工具。用户没要求梳理知识时，不要动
