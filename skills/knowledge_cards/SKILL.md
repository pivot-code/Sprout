# 知识卡片生成

## 什么时候用

当用户提出以下类型的需求时使用：

- "帮我做知识卡片"
- "把笔记变成复习卡片"
- "生成 XX 课的复习卡片"
- "我需要一些卡片来背"
- "帮我整理知识点，做成问答形式"

只要用户想**把课程笔记变成可复习的问答卡片**，就用这个 skill。

## 怎么用

调用 `generate_cards` 工具，参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `course_name` | 是 | 课程名，如 `智能感知技术`。只从这门课的笔记生成 |
| `source_file` | 否 | 只从某一份笔记生成。留空表示处理整门课 |
| `cards_per_note` | 否 | 每份笔记生成几张卡片，默认 5 |
| `save` | 否 | 是否保存到 `cards/`，默认 true |

### 关于 course_name

**必填。**用户必须指定是哪门课。

- 用户说"帮我做知识卡片" → 问用户"哪门课？"
- 用户说"智能感知技术的知识卡片" → `course_name="智能感知技术"`
- 用户说"做计算机网络和智能感知技术的" → 分别调用两次（一次一门课）

**不要自己猜课程名。**如果用户没说，先问清楚。

### 关于 cards_per_note

- 用户说"多来点" → 改成 8-10
- 用户说"少一点" → 改成 3
- 用户没说 → 默认 5

## 输出

工具会把卡片保存到：

- `cards/{课程名}/{时间戳}_cards.md`

并在对话里返回预览。

**你应该：**

- 告诉用户保存位置和卡片总数
- 展示预览
- 告诉用户"想复习的时候可以说'开始复习 XX 课'"

## 重要边界

**本工具只从课程笔记（`courses/`）生成卡片。**

**不处理**：

- `papers/` 下的论文解读
- `arxiv_papers/` 下的抓取结果
- `digests/` 下的网页笔记
- `comparisons/`、`maps/` 等派生产物

**原因：**知识卡片是用于**考试复习**的，只有课程内容需要复习。论文是为了参考和研究，不需要背。

如果用户说"帮我把论文也做成卡片"，回应：

> "知识卡片主要用于考试复习，一般只从课程笔记生成。论文更适合做'解读'和'对比'，如果你想回顾读过的论文，我可以帮你检索。"

## 示例

**例 1：整门课**

用户："帮我做智能感知技术的知识卡片"

做法：调用 `generate_cards(course_name="智能感知技术")`。

**例 2：只做某一章**

用户："只做电感式传感器那一章的卡片"

做法：调用 `generate_cards(course_name="智能感知技术", source_file="5.电感式传感器_notes.md")`。

**例 3：没指定课程**

用户："帮我做知识卡片"

做法：**先问用户**"哪门课？"，不要自己猜。

## 注意

- `course_name` 必填，不要猜
- 如果课程下还没有笔记，工具会提示用户先用 `digest_course_material` 消化资料
- 卡片是给用户复习用的，**展示预览 + 告诉他文件位置**，不要贴全部
