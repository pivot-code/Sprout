  Sprout v1.0 — 学习成长智能体 使用安装说明书
====================================================================

【系统简介】
Sprout是一个专注于辅助学习的 AI 智能体系统。
基于 LangChain + LangGraph 构建，支持 arXiv 文献抓取、论文深度解读、
课堂资料消化、知识卡片生成、全库检索与定时任务推送，
旨在陪伴用户完成“获取-消化-积累-回顾”的学习闭环。

====================================================================

【环境要求】
- Python 3.10 或以上版本
- Windows 10 / 11 操作系统
- DeepSeek API Key（免费注册获取：https://platform.deepseek.com/api_keys）

====================================================================

【安装步骤】

第一步：解压安装包
  将 Sprout-v1.0.zip 解压到任意目录（建议纯英文路径，如 D:\Sprout\）

第二步：运行安装脚本
  双击 install.bat，脚本会自动完成：
  1. 检测 Python 环境
  2. 创建虚拟环境（.venv）
  3. 安装所有依赖包（约 2-3 分钟）
  4. 生成配置文件模板

第三步：配置 API 密钥
  用记事本打开 .env 文件，填入你的 DeepSeek API Key：
    DEEPSEEK_API_KEY=sk-你的密钥
  API Key 获取地址：https://platform.deepseek.com/api_keys

第四步：启动系统
  双击 start.bat，约 8 秒后浏览器自动打开。
  默认地址：http://127.0.0.1:8000

====================================================================

【核心功能说明】

1. 论文与研究工作流
   - 找论文：“帮我找 5 篇关于 multi-agent 的最新论文”
   - 下论文：“把刚才的 PDF 下载下来”
   - 读论文：上传 PDF，说“帮我深度解读这篇论文”
   - 比论文：“对比刚才那两篇论文”

2. 课堂与复习
   - 消化资料：上传 PPT/PDF，说“整理成笔记，存到计算机网络课”
   - 出题自测：“从计算机网络出 3 道题”
   - 知识卡片：“帮我做计算机网络的知识卡片”
   - 知识地图：“帮我生成知识地图”

3. 主动型定时任务
   - 进入左侧“任务”面板，点击“+ 新建任务”
   - 可配置“每天 20:00 自动抓取论文并下载 PDF”
   - 任务执行完毕后，结果推送到左侧“🔔 通知”会话

4. 对话聊天
   - 输入框输入消息，Enter 发送，Shift+Enter 换行
   - 支持多会话管理（左侧 + 按钮新建对话）
   - 对话历史自动持久化，刷新不丢

5. 权限模式（重要）
   - 完全权限：Agent 可自由操控电脑文件和命令行
   - 询问权限：每次工具调用需要用户确认（推荐）
   - 安全模式：仅限聊天和数据分析，不能操控电脑

6. 主题切换
   - 左下角 🌓 按钮切换“生机绿”与“深林色”主题

====================================================================

【添加新的 AI 模型】

1. 进入“设置” → “Provider 管理”
2. 点击 “+ 添加 Provider”
3. 填写信息：
   - 名称：如 "Zhipu GLM"
   - API Key：你的 API 密钥
   - Base URL：API 地址（不带 /v1）
   - 运行时类型：DeepSeek / Qwen / OpenAI兼容
   - Opus/Sonnet/Haiku：分别填对应模型名
4. 保存后在对话页顶部下拉框切换

【常见问题】

Q: 启动提示 "DEEPSEEK_API_KEY not found"
A: 检查 .env 文件是否存在并填入正确的 API Key

Q: 浏览器显示"无法连接"
A: 等待服务器窗口显示 "Application startup complete" 后刷新

Q: 端口被占用
A: 编辑 .env 文件，修改 API_PORT 为其他端口（如 8008）

Q: 依赖安装失败
A: 尝试以管理员身份运行 install.bat

Q: 定时任务没有触发
A: 检查任务列表中的“上次运行”时间，若为你设定的时间，说明已成功触发；
   若一直为“从未”，请确认 start.bat 窗口是否关闭。
